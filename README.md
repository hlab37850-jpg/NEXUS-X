# NEXUS X

Arabic-first Flutter Android development workspace.

## Cloud APK build

Push to `main` or manually run the GitHub Actions workflow named
**NEXUS X Android APK**.

The workflow analyzes Dart, runs Flutter tests, builds a debug APK on
GitHub-hosted runners, and uploads the APK as a workflow artifact.

## Current status

The initial Arabic RTL interface is available. GitHub repository management,
AI provider integration, and live build status require further implementation.
No live connection or successful build is assumed until verified.
